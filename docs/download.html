常见问题

关于下载和使用，你可能想问的

离线版需要联网吗？

首次打开需要联网（自动从云端同步最新数据，约 2-3 秒）。之后会缓存最近一次数据，断网也能浏览已缓存内容。

离线版能在别的电脑上用吗？

能。把 离线版.html 这一个文件拷到 U 盘 / 微信 / 网盘，在任意 Windows / Mac 电脑上双击即可打开，无需安装任何东西。

数据是从哪里来的？

GitHub Actions 每 6 小时自动抓取 GitHub / Hacker News / Hugging Face / 新智元 / 量子位 等信源的热门 AI 项目，云端累积、只增不减。

我电脑关机了，数据还会更新吗？

会。抓取跑在 GitHub 云端服务器上，与你电脑完全无关。任何时候打开应用，看到的一定是最新数据。

英文简介看不懂怎么办？

不需要担心。云端已经自动把英文简介翻译成中文（免费机器翻译），只有极少数翻译失败的才会显示英文原文。

项目会越来越多还是越来越少？

只增不减。历史项目永久保留，应用内可开启"本月热门"筛选只看当月热点。
