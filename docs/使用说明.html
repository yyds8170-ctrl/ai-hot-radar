01 / 09

这是什么

「AI 热门项目雷达」是一个为你（电商美工）定制的 AI 工具发现站。它做三件事：

  • 扫描——定时从 Hacker News 和 GitHub 抓取最近热门的 AI 项目、开源仓库、新模型；
  • 筛选——自动按「AI服装换装 / AI视频生成 / AI图像/电商设计 / AI新模型 / 效率工具」五类归档，优先展示对你工作最有用的；
  • 沉淀——内置 32 条人工精选项目，加上每天自动新增的条目，你可以收藏、添加自己的、随时一键直达官网。

它由两部分组成：云端仓库（GitHub 上的定时任务，负责自动抓取）和本地应用（一个 HTML 文件，负责展示和你的私人数据）。

⚡
一句话：你什么都不用做，每隔 6 小时全球的新 AI 项目会自动出现在你的雷达里。
02 / 09

30 秒快速开始

  1. 双击打开 AI热门项目雷达.html——任何系统（Windows / Mac）的任意现代浏览器都行，不需要安装任何东西。
  2. 等待顶部状态显示「云端已连接」，项目卡片会自动加载出来（首次约 2-3 秒）。
  3. 用顶部分类标签切换五个方向，或在搜索框输入关键词（如 换装、视频、comfyui）。
  4. 点卡片上的「直达 ↗」访问项目官网；点 ☆ 收藏；点「展开详情」看介绍和「对电商美工的用处」。
💡
建议：把这个 HTML 文件固定到浏览器书签栏，或在桌面创建快捷方式，每天早上点开扫一眼有没有新工具。

04 / 09

自动更新的原理

这是整个雷达最核心的机制，理解它你就知道为什么「关机也能更新」。

数据流

GitHub Actions（云端，每6小时）
    │  运行 crawler.mjs 抓取脚本
    ├──► Hacker News API  ──┐
    └──► GitHub Search API ──┤
                            ▼
                    自动分类 + 去重
                            │
                            ▼
                    更新 data.json 并提交到仓库
                            │
                            ▼
            jsDelivr CDN 分发（全球加速）
                            │
                            ▼
            你的浏览器打开 HTML 时读取最新 data.json

关键事实

  • 定时任务跑在 GitHub 的服务器上，不依赖你的电脑开机；
  • 频率：每 6 小时一次（北京时间约 6:00 / 12:00 / 18:00 / 24:00）；
  • 每次抓取 Hacker News 热门 AI 帖 + GitHub 上 16 组关键词的热门仓库，自动取 top 40；
  • 结果存成 data.json，通过 CDN 全球分发，你打开应用时读到的永远是最新版；
  • 仓库公开可见：github.com/yyds8170-ctrl/ai-hot-radar。

想立刻抓一次（不等 6 小时）

两种方式：

  1. 在应用里点「立即刷新」——重新拉取云端已有的最新数据；
  2. 去 Actions 定时任务页，点右侧 Run workflow，等 1 分钟左右抓取完成，再回应用点「立即刷新」。
🔐
关于 Token：云端定时任务用的是 GitHub 自动提供的临时凭证，你的私人 Token 没有写进任何代码，只存在你自己浏览器里（用于云端不可用时的降级直连）。

在其他电脑上使用

这是单文件应用，迁移极其简单：

  1. 复制文件——把 AI热门项目雷达.html 这一个文件拷到 U 盘、微信文件传输助手、网盘、或发给自己。
  2. 在任意电脑上双击打开——Windows、Mac 都行，只要有 Chrome / Edge / Safari 等现代浏览器，无需安装、无需联网即可打开界面。
  3. 联网即自动同步——有网络时会自动从云端读取最新项目数据；没网时显示上次缓存 + 32 条精选。
⚠️
注意：收藏夹和你手动添加的项目保存在各自浏览器的本地存储里，不会跟着文件走。换电脑前请先用「导出」按钮备份，到新电脑后用「导入」恢复（见第 7 节）。

多设备保持收藏同步的技巧

每次在一台电脑上新增收藏或项目后，点一次导出，把 JSON 备份存到网盘；换设备时导入即可。也可以把备份文件发给自己的微信/邮箱，随时恢复。

06 / 09

添加与管理项目

手动添加

点顶部「＋ 添加项目」，填表即可：

  • 名称、分类、一句话简介、链接为必填；
  • 「详细介绍」和「对我有什么用」建议认真写——以后翻回来时这是最有价值的信息；
  • 标签用逗号分隔，如 换装, 开源, ComfyUI；
  • 你添加的项目会显示 ✏️ 我的 角标，只存在本浏览器。

收藏

点卡片右上角的 ☆ 收藏，再点取消。点顶部的 ☆ 按钮可只看收藏。适合把「想试用」「常用」的项目单独筛出来。

编辑与删除

自动抓取来的项目如果信息有误，你可以覆盖编辑（修改保存在本地，不会影响云端数据）。删除后该链接会加入黑名单，后续抓取不会再出现。

💡
用法建议：把「对我有什么用」写成你自己的工作场景备注，比如「详情页第二屏换背景用」「拍夹克前出草图」，三个月后翻回来依然知道这工具当时是干嘛的。
07 / 09

备份与迁移

顶部工具栏有两个按钮：

⬆ 导出把你的收藏、自定义项目、编辑记录、黑名单打包成一个 JSON 文件下载，文件名带日期
⬇ 导入选择之前导出的 JSON，自动合并（收藏合并、自定义项目按链接去重、黑名单合并）

建议每月导出一次备份，或在换电脑、清理浏览器缓存前导出。备份文件很小（通常几十 KB），可以放心存网盘。

08 / 09

离线使用

  • 完全断网也能打开应用——会显示内置的 32 条精选项目 + 上次联网时缓存的自动抓取数据；
  • 离线时不能获取最新数据、不能打开外部链接，但收藏、搜索、筛选、添加项目都正常；
  • 重新联网后会自动同步云端最新数据，无需手动操作。
09 / 09

常见问题

电脑关机时真的会更新吗？

会。抓取任务运行在 GitHub 的云端服务器上，和你的电脑无关。你关机、睡觉、断网，它照样每 6 小时跑一次。下次你在任何设备打开应用，读到的都是最新数据。

别人能看到我的收藏和添加的项目吗？

看不到。收藏和自定义项目只存在你本地浏览器里，不会上传到任何服务器。公开的 GitHub 仓库里只有自动抓取的项目数据和抓取脚本，不含任何你的个人数据。

云端仓库是公开的，有安全问题吗？

没有。仓库里只有抓取脚本、说明文档和公开的项目信息（项目名、链接、简介，这些本来就是 HN/GitHub 上公开的）。没有你的 Token、没有任何密钥。你的 GitHub 用户名是公开的 GitHub 身份，无敏感风险。

怎么改更新频率？

目前是每 6 小时一次。想改成每小时、每天、或每周，告诉我即可，我帮你改云端配置（一行代码的事）。也可以随时去 Actions 页面手动触发。

能加新的数据源吗？比如 Product Hunt、X、特定博客？

可以。Product Hunt 需要 API Token，X/Twitter 抓取限制较多，特定博客/RSS 比较容易加。把你想盯的网站告诉我，我评估后加到抓取脚本里，下次定时任务就会开始抓。

打开后显示「云端未连接」怎么办？

通常是网络问题（CDN 访问不畅）。应用会自动降级使用本地缓存和内置精选数据，不影响浏览。可以点「立即刷新」重试，或检查网络。长期连不上可能是当前网络屏蔽了 jsDelivr CDN，告诉我，我可以换一个数据地址。

清理浏览器缓存会丢数据吗？

会——收藏和自定义项目存在浏览器本地存储里，清理缓存会清除它们。清理前一定先点「导出」备份，清完再「导入」恢复。云端的自动抓取数据不受影响。

手机上能用吗？

能。把 HTML 文件发到手机（微信/AirDrop/网盘），用手机浏览器打开即可，界面已适配小屏。但手机浏览器的本地存储可能在清理微信/浏览器缓存时被清除，同样建议定期导出备份。

怎么彻底卸载/重置？

直接删除 HTML 文件即可。若要清空本地数据，在浏览器里清除该文件的站点数据（LocalStorage），或在应用里删除所有自定义项目。云端仓库如果不想要了，去 GitHub 仓库 Settings → 最底部 Delete this repository。
